# 共用合成样例

| 目录 | 用途 |
|---|---|
| `qce/` | 手写/合成的 QCE JSON：元素类型、重叠导出、回复、撤回、转发等 |
| `jsonl/` | CLI 信封与事件序列：供 core 测试、GUI 开发和 eval 接入共用 |
| `models/` | 手写/合成的 Jev / LLM 请求响应，包含失败与重试场景 |

这些子目录随样例加入而创建。目前本文件只规定归属，不表示已有完整样例集。

- 只提交合成内容，真实服务产生的聊天/模型响应放 `eval/private/` 或 `private/`。
- 一个场景尽量保留一个权威样例，各 crate 直接引用；不要各自复制再修改协议字段。
- 样例是人工设计的预期输入输出，不在每次测试前从被测实现自动重写预期值。
- 协议样例必须说明 schema_version，序号连续，以一个 done 结束；部分失败也要有独立样例。
- 带完整标注、用于算指标的合成聊天放 `eval/synthetic/`。

完整目录设计见 [FILE_LAYOUT.md](../docs/FILE_LAYOUT.md)。
