# ADR-0009 规则限定 + Jev 选择的有界控制器

**背景**：作业要求体现“AI 智能体”。纯 if-else 的流水线会被质疑“只是流水线”；完全交给 LLM 自主规划又不可控、不可复现，成本也不可预测。

**决策**
- 每一步：规则根据观测算出**允许的动作集合** → 只有一个候选时直接执行 → 有多个候选时用 Jev `choice` 选择（state 中只放分档后的类别，不放原始数字）→ Jev 失败时用规则默认项。
- 动作：`AnalyzeDirect`、`Segment`、`AnalyzeTopic`、`Verify`、`MergeTopics`、`Finish`。
- 硬上限：`max_steps`、`budget_usd`、取消信号。另外，按字典序比较 `(待切分消息数, 活跃话题数 + 脏话题数, 待校验结论数)`，每个动作都让它严格减小，因此即使没有硬上限，循环也一定终止。
- 每一步（观测、候选、选择、概率、理由）都写入决策日志，GUI 可以展示。

**理由**
- 模型只在真正需要语言理解的分叉点（例如“先合并话题还是先抽取”“直接分析还是先切分”）做选择，其余由规则保证安全，比如必须先校验。
- 决策日志和概率让“智能体在哪里做了决定、依据是什么”可以回答，也可以审计。
- 可复现：同样的输入和缓存，得到同样的决策序列。

**代价**
- 智能体的自主程度有限，这是有意的取舍。答辩时的说法：有界自主 + 可审计。
