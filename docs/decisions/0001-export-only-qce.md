# ADR-0001 只读取 QCE 导出文件，不内嵌 QCE

**背景**：QQChatExporter（QCE，github.com/shuakami/qq-chat-exporter）是 GPL-3.0 许可证；它通过 NapCatQQ 接入 QQNT 协议抓取消息。本项目是 MIT 许可证。

**决策**：只读取 QCE 导出的 JSON 文件。不链接、不复制 QCE 的任何代码，也不依赖 NapCat 做实时抓取。

**理由**
- 许可证：链接或复制 GPL-3.0 代码会迫使本项目整体采用 GPL-3.0。只读取它生成的数据文件，不构成衍生作品。
- 依赖：NapCat 需要登录 QQ、维护协议兼容性，3 天内无法稳定支撑演示；对作业目标（智能体系统）也没有帮助。
- 解耦：导出文件是稳定的边界，适配器 `crates/qce` 可以独立测试。

**代价**
- 无法实时获取新消息，用户要手动导出（“回来补群”场景下可以接受）。
- QCE 的导出格式变化时需要更新适配器。缓解：记录参考的 QCE commit（`7fcca88`），反序列化时忽略未知字段，遇到未知元素类型用占位符并发出警告。
